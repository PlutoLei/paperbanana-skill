# Hyperrealism

Extremely detailed photorealistic style with lifelike textures and precision

## Design Aesthetic

Ultra-precise visual language that pushes photographic realism beyond photography itself. Incredibly detailed surfaces, textures, and lighting create an almost uncanny level of fidelity. Clean, focused compositions where every pixel serves the illusion of reality, delivering content with authoritative visual clarity.

## Background

- Color: Neutral White (#FAFAFA) or Soft Light Gray (#F0F0F0)
- Texture: Smooth matte or ultra-subtle paper grain, almost imperceptible

## Typography

### Primary Font (Headlines)

Refined thin-weight sans-serif like Helvetica Neue Light or SF Pro Display Thin. Precision and clarity. Minimal visual interference with photorealistic imagery.

### Secondary Font (Body)

Clean neutral sans-serif like Inter or Roboto. Exceptional readability. Technical precision in every letterform.

## Visual Elements

- Ultra-high-resolution photography with macro detail
- Dramatic shallow depth-of-field effects
- Photorealistic rendering of textures (skin, metal, glass, fabric)
- Precise drop shadows and ambient occlusion
- Clean full-bleed images with text overlays
- Side-by-side detail comparison views
- Subtle reflection and refraction effects
- Studio lighting with controlled highlights and shadows

## Style Rules

### Do

- Use only the highest resolution imagery available
- Maintain precise, controlled lighting in all visuals
- Focus on surface detail and texture fidelity
- Keep layouts clean and let imagery dominate
- Use typography that recedes behind the visuals

### Don't

- Apply artistic filters or stylization
- Use cartoon, sketch, or abstract elements
- Allow pixelated or low-resolution images
- Create busy layouts that distract from detail
- Add slide numbers, footers, or logos

## Best For

Product showcase presentations, automotive reveals, architecture visualization, medical imaging talks, scientific photography, industrial design reviews, portfolio presentations requiring maximum visual fidelity
