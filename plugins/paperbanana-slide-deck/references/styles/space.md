# Space

Cosmic science fiction style with celestial imagery, nebulas, and deep-space atmosphere

## Design Aesthetic

Vast and awe-inspiring compositions set against the infinite canvas of deep space. Rich nebula colors, star fields, and planetary bodies create a sense of cosmic wonder. The visual language bridges hard science fiction with the sublime beauty of astronomical photography.

## Background

- Color: Deep Space Black (#0A0A1A)
- Texture: Dense star field with subtle nebula glow and cosmic dust particles

## Typography

### Primary Font (Headlines)

Orbitron or similar geometric, futuristic sans-serif. Clean, wide letterforms with a technological edge. Evokes spacecraft interfaces and mission control displays.

### Secondary Font (Body)

IBM Plex Sans or similar technical sans-serif for body text. Clean and functional at all sizes. Space-agency documentation quality.

## Visual Elements

- Star field backgrounds with varying density
- Nebula cloud effects with soft color gradients
- Planetary ring and orbit path motifs
- Constellation line patterns connecting elements
- Lens flare and light bloom effects
- Spacecraft and satellite silhouettes
- Grid overlays suggesting heads-up displays
- Radial burst patterns from light sources

## Style Rules

### Do

- Use deep, dark backgrounds with luminous accents
- Create depth through layered cosmic elements
- Apply subtle glow effects to key focal points
- Use vast scale to emphasize cosmic grandeur
- Maintain a balance between scientific precision and wonder

### Don't

- Use bright, daylit backgrounds
- Include mundane, earthly, ground-based imagery
- Apply flat, textureless compositions
- Use warm, cozy color palettes
- Create cluttered or small-scale layouts

## Best For

Astronomy and astrophysics talks, science fiction world-building, technology vision presentations, space exploration proposals, futuristic product launches, visionary keynotes
