# Infographic Drawing

Data-rich visual storytelling with clear diagrams, icon systems, and structured information hierarchy

## Design Aesthetic

Clean, information-first design that transforms complex data into accessible visual narratives. Combines illustrated icons, charts, and diagrammatic layouts into cohesive visual stories. Structured hierarchy guides the eye through information in a logical flow. Professional yet approachable, prioritizing clarity and comprehension above all.

## Background

- Color: Light Gray (#F5F5F5) or Clean White (#FFFFFF)
- Texture: Flat and clean with subtle section dividers and flow lines

## Typography

### Primary Font (Headlines)

Bold sans-serif with strong weight contrast for clear hierarchy. Wide or extended proportions for impactful headers. Often paired with large numerical callouts.

### Secondary Font (Body)

Regular-weight sans-serif optimized for small sizes and dense information. Open letterforms with clear distinction between similar characters. Functional above all.

## Visual Elements

- Consistent icon system with uniform stroke weight
- Flow charts and process diagrams with directional arrows
- Bar charts, pie charts, and data visualization elements
- Large numerical callouts for key statistics
- Section dividers with connecting flow lines
- Pictogram rows for comparative data
- Timeline and milestone markers
- Color-coded legend and category systems

## Style Rules

### Do

- Establish a clear visual hierarchy for information flow
- Use a consistent icon style throughout
- Apply color coding systematically with legends
- Make data the hero of every composition
- Maintain generous spacing between information groups

### Don't

- Prioritize decoration over data clarity
- Use inconsistent icon styles or line weights
- Create ambiguous flow directions
- Overcrowd sections with competing data points
- Add slide numbers, footers, or logos

## Best For

Annual reports, data storytelling presentations, research findings summaries, market analysis decks, process documentation, healthcare statistics, educational curricula overviews
