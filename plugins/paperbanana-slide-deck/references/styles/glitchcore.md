# Glitchcore

Digital distortion aesthetic with chromatic aberration, pixel corruption, and vibrant neon chaos

## Design Aesthetic

Deliberately broken digital aesthetic that celebrates errors, corruption, and signal interference as art. RGB channel splits, scan lines, pixel sorting, and data moshing create a hypnotic visual chaos. Vibrant neon colors clash against dark backgrounds in an aggressive, cyberpunk-adjacent style that feels like a corrupted transmission from the future.

## Background

- Color: Void Black (#0A0A0A) or Deep Dark Purple (#0D0015)
- Texture: Scan lines, static noise, and horizontal displacement artifacts

## Typography

### Primary Font (Headlines)

Glitched or distorted monospaced font with visible corruption effects. RGB channel offset on letterforms. Bold and aggressive with digital artifacts baked into the type treatment.

### Secondary Font (Body)

Clean monospaced or pixel font for contrast against visual chaos. Terminal-style aesthetic. Provides legibility anchor amid the glitch effects.

## Visual Elements

- RGB chromatic aberration offset on text and images
- Horizontal scan lines and VHS tracking errors
- Pixel sorting and data-bent image regions
- Screen tear and displacement glitch bands
- Static noise patches and dead pixel clusters
- Corrupted bar code and QR code fragments
- Flickering neon glow effects on key elements
- Digital rain and matrix-style cascading characters

## Style Rules

### Do

- Apply chromatic aberration to headlines and key visuals
- Use horizontal displacement and scan line effects
- Contrast chaotic visuals with readable body text
- Layer multiple glitch effects for depth
- Keep the base palette dark with neon punctuation

### Don't

- Make text completely unreadable through over-distortion
- Use soft pastels or warm earth tones
- Apply organic hand-drawn textures
- Create calm, orderly grid layouts
- Add slide numbers, footers, or logos

## Best For

Cybersecurity talks, electronic music events, digital art showcases, hacker conferences, VR/AR technology demos, experimental media presentations, gaming culture content
