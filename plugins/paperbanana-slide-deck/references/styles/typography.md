# Typography

Stylized text-based art where letterforms and type compositions are the primary visual elements

## Design Aesthetic

Type-forward visual language where letterforms themselves become the artwork. Letters are sculpted, layered, and composed as graphic objects rather than mere text carriers. Intricate typographic arrangements, creative letter manipulation, and artistic text layouts transform words into visual experiences.

## Background

- Color: Pure White (#FFFFFF) or Deep Black (#0A0A0A)
- Texture: Clean and flat, allowing type to be the sole texture

## Typography

### Primary Font (Headlines)

Bold experimental display type like Dela Gothic One, Anton, or custom lettering. Type IS the design element. Variable weight, decorative, or hand-lettered styles.

### Secondary Font (Body)

Contrasting clean sans-serif like Helvetica Neue or Work Sans. Functional readability providing visual rest between typographic artwork.

## Visual Elements

- Oversized display letterforms as hero elements
- Layered and stacked text compositions
- Letters used as clipping masks for imagery
- Kinetic typography-inspired arrangements
- Creative text wrapping and path-following type
- Mixed typeface collages within single compositions
- Negative space letterform cutouts
- Typographic grids and modular type systems

## Style Rules

### Do

- Make letterforms the primary visual element
- Experiment with scale, weight, and orientation of type
- Use creative layouts that treat text as art
- Maintain high contrast for maximum letter impact
- Mix typefaces intentionally for visual tension

### Don't

- Relegate type to a secondary supporting role
- Use only standard paragraph text layouts
- Apply photographic imagery as the main element
- Create illegible compositions that sacrifice meaning
- Add slide numbers, footers, or logos

## Best For

Brand identity presentations, type foundry showcases, graphic design portfolios, editorial layout proposals, book launch events, design education talks, creative agency capability decks
