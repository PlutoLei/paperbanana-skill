# Cubism

Fragmented geometric forms showing multiple perspectives simultaneously in bold angular compositions

## Design Aesthetic

Revolutionary visual language that deconstructs subjects into flat geometric facets viewed from multiple angles at once. Inspired by Picasso and Braque, compositions feature overlapping angular planes, muted earth tones punctuated by bold accents, and a deliberate rejection of single-point perspective. The effect is intellectually stimulating and visually dynamic.

## Background

- Color: Warm Taupe (#D2C4A5) or Muted Sand (#E5D9C5)
- Texture: Linen canvas texture with visible weave, newspaper collage fragments

## Typography

### Primary Font (Headlines)

Angular geometric sans-serif with sharp edges. May feature fragmented or overlapping letterforms to echo the cubist aesthetic. Strong, assertive presence.

### Secondary Font (Body)

Condensed sans-serif or newspaper-style serif for readability. Slightly compressed proportions that complement angular compositions. Clean enough to read within fragmented layouts.

## Visual Elements

- Overlapping angular planes and faceted forms
- Multiple viewpoints of the same subject shown simultaneously
- Newspaper and printed text collage fragments
- Bold angular outlines segmenting forms
- Semi-transparent overlapping color planes
- Faceted portraits or object deconstructions
- Geometric pattern backgrounds within panels
- Guitar, bottle, and still-life motifs as decorative elements

## Style Rules

### Do

- Fragment subjects into flat geometric facets
- Show multiple angles of the same object
- Use overlapping transparent planes for depth
- Maintain earth-tone dominance with selective bright accents
- Include collage-like mixed-media elements

### Don't

- Use smooth curves or organic flowing shapes
- Apply realistic perspective or shading
- Include photographic elements
- Use bright saturated color palettes
- Add slide numbers, footers, or logos
