# Bauhaus-Style Poster

Bold geometric compositions with primary colors, clean lines, and functional modernist design

## Design Aesthetic

Strict geometric abstraction rooted in Bauhaus principles of form follows function. Primary colors dominate alongside black and white, with shapes reduced to circles, triangles, and rectangles. Clean sans-serif typography integrates seamlessly with the composition. Every element serves a purpose with no decoration for its own sake.

## Background

- Color: Pure White (#FFFFFF) or Warm Off-White (#F5F0E8)
- Texture: Flat matte finish with crisp, clean edges throughout

## Typography

### Primary Font (Headlines)

Bold geometric sans-serif in the tradition of Futura or DIN. Strong vertical rhythm with perfect circles and strict geometry. Often set in uppercase with generous letter-spacing.

### Secondary Font (Body)

Medium-weight geometric sans-serif. Clean and functional with excellent readability. Consistent stroke widths and rational proportions.

## Visual Elements

- Bold circles, triangles, and rectangles as core compositional elements
- Strong horizontal and vertical grid lines
- Overlapping transparent color shapes
- Asymmetric but balanced layouts
- Thick black outlines and rules
- Typographic hierarchy as a design element itself
- Geometric icons reduced to essential forms
- Color blocks used as spatial dividers

## Style Rules

### Do

- Restrict palette to primary colors plus black and white
- Use strict geometric shapes only
- Maintain a visible grid structure
- Let typography function as graphic element
- Keep every element purposeful and functional

### Don't

- Add organic curves or hand-drawn elements
- Use gradients, shadows, or 3D effects
- Include photographic imagery
- Apply decorative ornamentation
- Add slide numbers, footers, or logos
