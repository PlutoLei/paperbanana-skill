# Bauhaus Style

Geometric minimalism with primary colors, asymmetric layouts, and functional sans-serif typography

## Design Aesthetic

Rooted in the Bauhaus school's principle that form follows function. Geometric precision meets bold primary colors across asymmetric compositions. Every element serves a purpose; ornamentation is eliminated. Clean sans-serif type and mathematical grid structures create a rational, modern visual language.

## Background

- Color: Pure White (#FFFFFF) or Light Warm Gray (#F2F0EB)
- Texture: Flat, clean surface with no visible grain or noise

## Typography

### Primary Font (Headlines)

Geometric sans-serif in bold or extra-bold weight. Futura, DIN, or Bauhaus-inspired faces. Often set in all-lowercase or all-caps with tight tracking. Strong vertical and circular letterforms.

### Secondary Font (Body)

Light-weight geometric sans-serif. Highly legible at small sizes, maintaining the same geometric DNA as the headline face.

## Visual Elements

- Bold geometric shapes: circles, triangles, rectangles as primary compositional units
- Strong horizontal and vertical grid lines creating asymmetric balance
- Thick black rules separating content zones
- Primary color blocks as background fills for sections
- Diagonal lines and overlapping geometric forms for dynamism
- Sans-serif numerals used as large decorative elements
- Negative space used deliberately as a compositional tool
- Minimalist icons reduced to pure geometric essentials

## Style Rules

### Do

- Use only primary colors plus black and white
- Maintain strict geometric precision in all shapes
- Embrace asymmetric layouts on a visible grid
- Keep typography purely sans-serif and functional
- Let negative space breathe between elements

### Don't

- Add ornate decoration or intricate patterns
- Use serif typefaces or script fonts
- Create complex, multi-layered textures
- Include organic or hand-drawn shapes
- Add slide numbers, footers, or logos
